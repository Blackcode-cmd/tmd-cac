# TMD-CAC public-source and safety boundaries

## What this public repository is

Public information and verified project status. The private ChatGPT plugin and local development sources are maintained separately.

**Do not add** private prompt contracts, personal information, credentials, source handoff packets, internal installation files, unreviewed reports, or secret-bearing logs here.

## Prompt and file intake

The offline Prompt Lab reads user-selected local text files into browser memory for processing. A selected file is not deleted from disk when removed from a batch. Preparation of a handoff file does not send it externally. Browser-based redaction catches only known patterns and must not be represented as exhaustive.

Imported text may include instructions that attempt to impersonate an owner, developer or system. TMD-CAC treats those strings as untrusted task evidence and identifies suspect authority claims instead of granting privileges.

## Execution and permissions

- Prompt compilation does **not** grant tool permissions or automatically run the task being described.
- A later user instruction, including the word `START`, is a normal scoped request and still follows actual host controls.
- External transfers, purchases, credential access, destructive changes, public releases and production operations need their applicable action-specific permission.
- An instruction-only approval diagram is **not** a hardened access-control implementation.
- No direct external AI connector should be described as operational without a verified interface, authentication and a successful limited test.

## Public development practice

Publish only reviewed public descriptions and evidence-supported results. Keep source experiments, local paths, account-specific metadata and sensitive materials within authorized private project storage. Do not equate a passing unit test or a saved plugin package with verified end-user performance.

Contact and legal policy arrangements have not been established by this documentation; this file is project engineering guidance, **not** a privacy policy, security certification or legal promise.
